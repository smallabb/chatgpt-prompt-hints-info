ChatGPT 需求提示：資料處理與隱私說明

更新日期：2026-10-11，適用版本：1.16.1。發布者：小賴工具箱。支援與隱私聯絡：smallabb@gmail.com。本擴充功能為獨立第三方工具，非 OpenAI 官方產品。

讀取哪些內容，為什麼讀取

啟用時，本工具在 chatgpt.com 讀取輸入框文字，以本機規則提醒需求條件；延續提示參考目前頁面可讀取的近期使用者訊息。進階判斷預設開啟，在規則無法辨識且文字符合分析條件時，將文字交由內附 BGE 模型在本機推測類別，結果仍需使用者確認，可在工具列關閉。文字不會送到模型供應商。

作品預覽會讀取 AI 回覆中的完整 HTML 程式碼，或使用者主動貼上／匯入的 HTML。最新作品卡片會自動展開隔離預覽；沉浸式試玩需按下執行按鈕。预覽程式無擴充 API 或父頁 DOM 存取權，並限制網路連線與外部資源。這不保證任意生成程式的品質或效能。

保存與刪除

啟用設定、進階判斷設定及個人選項保存在 chrome.storage.local，不使用 Chrome 同步儲存。按「加入需求」時，手動填入的自訂片段會保存為該欄位選項；即使後續寫入輸入框失敗，已成功保存的選項仍會保留。可在各欄位的編輯清單刪除，或恢復預設後儲存。解除安裝可移除擴充功能的本機儲存資料。

本工具不持久保存完整草稿、整篇對話或預覽作品。分析及預覽期間的內容會暫存在記憶體；關閉相關頁面、停止預覽或結束工作程序會釋放相應內容。使用者自行下載的檔案、剪貼簿內容及分享副本需自行刪除。

傳輸與分享

本工具不將草稿或對話上傳至開發者伺服器，不加入廣告、追蹤或分析服務，不出售資料。模型與執行程式隨安裝包提供。按分享時，依瀏覽器支援開啟系統檔案分享或複製 HTML；目的地由使用者決定，不會自動建立公開網址。

本說明只涵蓋本擴充功能。使用者在 ChatGPT 送出的訊息依該服務的政策處理。下載的 HTML 離開本工具執行時不再受此沙盒限制，可能依檔案內容連線到外部服務。

控制與聯絡

可在工具列關閉提示或本機進階判斷。停用提示會停止頁面提示與對話讀取；手動匯入預覽仍可使用。發布後的支援與隱私問題請透過商店頁面的開發者聯絡方式提出。
